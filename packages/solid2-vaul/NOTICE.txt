Source mappings are recorded in each derived source file. Changes replace
React and Radix Dialog with native Solid 2 reactivity, callback refs, JSX,
contexts, lifecycle, presence, and DOM events. Drawer geometry, drag damping,
velocity thresholds, snap selection, background scaling, fixed positioning,
and directional CSS are adapted from Vaul. CSS also corrects the upstream
handle selector and supports native touch scrolling and reduced motion.
Exit motion uses Solid-controlled transitions without competing CSS keyframes.
Snap entry waits for viewport measurement and starts from the closed position.

Vaul's src/use-prevent-scroll.ts identifies Adobe React Spectrum as its
source. That file is not copied into this package. Accessibility and scroll
prevention use the separately licensed @solid2-aria/core dependency, whose Adobe
attribution and Apache-2.0 notices remain with that package.

Vaul's React-specific src/use-controllable-state.ts and src/use-composed-refs.ts
identify Radix UI as their source. Neither file is copied. Controlled signals
and ref arrays use Solid's native APIs.
