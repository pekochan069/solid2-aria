# @solid2-aria/types

Accessible UI component types for Solid 2, ported from Adobe React Spectrum.

Import types from component subpaths:

```ts
import type { AriaButtonProps } from "@solid2-aria/types/button";
import type { CalendarProps } from "@solid2-aria/types/calendar";
```

Shared declarations remain in `@solid2-aria/types-shared` and `@solid2-aria/types-shared-web`.

Run `bun run check-types` to check the component and shared declarations.
