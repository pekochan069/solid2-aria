# @solid2-aria/types-shared-web

Web attributes, renderer refs, and style types for Solid 2. Requires `solid-js` and `@solidjs/web` version `^2.0.0-rc.17`.

Import state and collection contracts from `@solid2-aria/types-shared`. Import web types such as `DOMAttributes`, `CSSProperties`, and `Ref` from this package.
