## Before you start

<Callout>

These components require Solid 2. If you have a Solid 1 app, follow the migration steps in your framework guide before installing components.

</Callout>

Install Node.js 22.12 or later and a package manager. The guide commands default to Bun, with tabs for npm, pnpm, and Yarn.

The accessibility package is available on npm. You can create the app in any directory without cloning the Solid Aria repository.

## Existing projects

Open the guide for your framework and continue at **Configure shadcn** after checking the Solid 2 and Tailwind CSS prerequisites.

Component installation preserves your stylesheet. Apply the shared theme separately when setting up a new app.

## Customize the theme

Use [Create](/create) to preview colors, fonts, and radius settings, then copy the theme settings into your app.

Continue with [theming](/docs/theming), [dark mode](/docs/dark-mode), or the [component documentation](/docs/components).
