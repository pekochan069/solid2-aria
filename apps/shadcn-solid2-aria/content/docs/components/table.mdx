## Usage

```tsx showLineNumbers
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "#components/ui/table";
```

```tsx showLineNumbers
<Table>
  <TableHeader>
    <TableHead isRowHeader class="w-[100px]">Invoice</TableHead>
    <TableHead>Status</TableHead>
    <TableHead>Method</TableHead>
    <TableHead class="text-right">Amount</TableHead>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell class="font-medium">INV001</TableCell>
      <TableCell>Paid</TableCell>
      <TableCell>Credit Card</TableCell>
      <TableCell class="text-right">$250.00</TableCell>
    </TableRow>
  </TableBody>
</Table>
<TableCaption>A list of your recent invoices.</TableCaption>
```

## Composition

Use the following composition to build a `Table`:

```text
Table
├── TableCaption
├── TableHeader
│   └── TableRow
│       ├── TableHead
│       ├── TableHead
│       ├── TableHead
│       └── TableHead
├── TableBody
│   ├── TableRow
│   │   ├── TableCell
│   │   ├── TableCell
│   │   ├── TableCell
│   │   └── TableCell
│   └── TableRow
│       ├── TableCell
│       ├── TableCell
│       ├── TableCell
│       └── TableCell
└── TableFooter
```

## Data Table

You can use the `<Table />` component to build more complex data tables. Combine it with [@tanstack/solid-table](https://tanstack.com/table/latest/docs/framework/solid/solid-table) to create tables with sorting, filtering and pagination.

Combine the table with your application’s sorting, selection, and filtering state.

You can also see an example of a data table in the [Tasks](https://ui.shadcn.com/examples/tasks) demo.
