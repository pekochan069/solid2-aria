# Solid2 Aria docs

Run the TanStack Start app with Bun. Install dependencies from the repository root:

```sh
bun install
```

From `apps/docs`, start the development server at <http://localhost:5173>:

```sh
bun run dev
```

Build and run the production server:

```sh
bun run build
bun run start
```

The Nitro server listens on port 3000 by default. Set `PORT` and `HOST` to change the address.

MDX files are compiled by Satteri with JSX preserved, then compiled by `@solidjs/vite-plugin` for Solid 2 server rendering and browser hydration. Content Collections loads each document's metadata and compiled component. Routes select a document from a collection and render it with `Markdown`:

```tsx
import { allSolid2AriaComponentsDocs } from "content-collections";

import { Markdown } from "../components/markdown";

function Page() {
  const document = allSolid2AriaComponentsDocs.find(
    (entry) => entry._meta.path === "mdx"
  );
  return document ? <Markdown document={document} /> : null;
}
```

MDX documents can import Solid components. `Markdown` supplies the document's native HTML components and merges element overrides from its `components` prop. Visit `/code-examples` for an interactive counter and a component/CSS code group.

To show component and style files in one compact example, import `CodeGroup` and wrap fenced code blocks. Supply one filename in `labels` for each block, in the same order. Keep a blank line between the wrapper and each fence so MDX parses the code blocks.

````mdx
import { CodeGroup } from "../../src/components/code-group";

<CodeGroup labels={["Button.tsx", "button.css"]} label="Button example files">

```tsx title="Button.tsx"
import "./button.css";

export function Button() {
  return <button class="button">Press me</button>;
}
```

```css title="button.css"
.button {
  padding: 0.5rem 1rem;
}
```

</CodeGroup>
````

Adjust the import path for the document's directory. Each file keeps Expressive Code highlighting, markers, and its copy button. Filename tabs replace the individual frame headers. Code scrolls within a height limit of 24rem or 60% of the viewport, whichever is smaller. The tab row scrolls horizontally on narrow screens. Readers can switch files with arrow keys, Home, or End.

Content Collections validates YAML frontmatter and indexes `**/*.mdx` in the three `content/solid2-*` directories. Each document requires a `title`; a `description` is optional. Import metadata from `content-collections` using `allSolid2StatelyDocs`, `allSolid2AriaDocs`, or `allSolid2AriaComponentsDocs`. Each collection entry includes `Content` and `components` references generated by Content Collections. Vite compiles these references for each rendering environment; routes do not import `.mdx` files or evaluate source strings.

See [Satteri's JSX output options](https://satteri.bruits.org/docs/options/#jsx-output) for the compiler settings used by this app.

## UI components

This app owns the components in `src/components/ui` and their class helper in `src/lib/cn.ts`. They are maintained locally. Shared UI animations and utilities are in `src/styles/ui.css`; the original shadcn MIT license is in `LICENSES/shadcn-ui-MIT.txt`.

Run this app's `dev`, `build`, and `check-types` commands directly. Its build and validation do not use another documentation app's registry, generator, or preview.
