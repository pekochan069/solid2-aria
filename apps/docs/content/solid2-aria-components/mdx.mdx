# MDX with Solid 2

Satteri compiles this document to JSX. The Solid 2 compiler turns that JSX into components for server rendering and browser hydration.

## Interactive components

Import Solid components directly into an MDX document, then use them alongside Markdown. This counter starts at two and updates when you press it.

## Component and styles

Keep related files in one code example. Select a filename to switch files, or use the arrow keys while a tab is focused.

<CodeGroup labels={["Counter.tsx", "counter.css"]} label="Counter example files">

```tsx title="Counter.tsx"
import { createSignal } from "solid-js";
import "./counter.css";

export function Counter() {
  const [count, setCount] = createSignal(0);

  return (
    <button class="counter" onClick={() => setCount((value) => value + 1)}>
      Count: {count()}
    </button>
  );
}
```

```css title="counter.css"
.counter {
  padding: 0.5rem 0.75rem;
  border: 1px solid currentColor;
  border-radius: 0.375rem;
  cursor: pointer;
}

.counter:hover {
  background: color-mix(in srgb, currentColor 10%, transparent);
}

.counter:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}
```
